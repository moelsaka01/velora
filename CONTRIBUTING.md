# Contributing to Velora

1. Open an issue before starting large changes.
2. One branch per change: `feat/<module>` or `fix/<topic>`; rebase on `main`.
3. Use Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`).
4. Open a small PR; CI must pass before merge.
5. Do not copy GPL code or any Apple/Microsoft proprietary code, icons, fonts or binaries.
6. Add reused Apache/MIT code to `THIRD_PARTY_NOTICES.md`.
7. Never terminate or modify other processes, `explorer.exe`, or system files.
8. Add tests for risky behavior (switching, recovery, file safety).
9. Record decisions in `docs/DECISIONS.md`.
10. By contributing you agree your work is licensed under Apache-2.0.
